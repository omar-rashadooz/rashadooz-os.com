نظام تشغيل صغير، مكتوب من الصفر. A small operating system, built from zero.

نواة x86 بحجم 46 كيلوبايت تقريباً، فيها تعدد مهام، وذاكرة افتراضية، ونظام ملفات، و shell، ولعبتين. هدفنا إنه يشتغل بسرعة على الأجهزة القديمة. A 46 KB x86 kernel with multitasking, virtual memory, a file system, a shell and two games. The goal: run fast on old hardware.

اللي جوّه النظامWhat's inside

كل جزء كتبناه بإيدينا خطوة خطوة، ومفيش مكتبات جاهزة. تقدر تقرا الكود كله وتفهمه.Every part was written by hand, step by step, with no ready-made libraries. You can read all of it.

تعدد مهامMultitasking

جدولة round-robin، وعمليات في وضع المستخدم بذاكرة معزولة، وfork وexec.Preemptive round-robin scheduler, isolated user-mode processes, fork and exec.

ذاكرة افتراضيةVirtual memory

paging بصفحات 4 كيلوبايت، ونواة في النص العالي، وheap للنواة.4 KB paging, a higher-half kernel and a kernel heap.

نظام ملفاتFile system

نظام RFS للقراءة فقط بيتحمّل مع الإقلاع، وأمر ls لاستعراضه.A read-only RFS image loaded at boot, browsable with ls.

Shell

أوامر help وversion وinfo وls وclear، وتشغيل أي برنامج من /bin بالاسم. والـ backspace شغال صح.help, version, info, ls and clear, plus any program in /bin by name. Backspace works as it should.

جرّبه في 3 خطواتTry it in 3 steps

أسهل طريقة هي QEMU، وهو مجاني ومتاح على Linux وWindows وmacOS.The easiest way is QEMU, which is free on Linux, Windows and macOS.

  1. حمّل الملفDownload the file

    اضغط زر التحميل فوق، وهتاخد ملف rashadooz.iso.Use the download button above to get rashadooz.iso.

  2. شغّله في QEMUBoot it in QEMU

    من الـ terminal في فولدر التحميل:From a terminal in the download folder:

    qemu-system-i386 -cdrom rashadooz.iso

  3. جرّب الأوامرTry the commands

    اكتب help عشان تشوف الأوامر، وبعدها snake أو tetris.Type help to see the commands, then snake or tetris.

النظام لسه تجريبي. لو هتجرّبه على جهاز حقيقي، استخدم جهاز تقدر تتحمل تجربته، وابدأ بـ CD أو USB. ولا تحطه على قرص فيه بيانات مهمة.The system is still experimental. If you try real hardware, use a machine you can afford to experiment on, and boot from a CD or USB. Never install it on a disk that holds data you care about.
